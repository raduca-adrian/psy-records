# Psychological Records Management System v1.0.0 - Release Package

## Distribution Files

This release contains two distribution options:

### 1. Portable Distribution (Recommended)
- **File**: `PsychologicalRecords-v1.0.0-Portable.zip` (49.7 MB)
- **Built with**: PyInstaller
- **Description**: Fully portable single-directory distribution
- **Installation**: Extract and run `PsychologicalRecords.exe`
- **Benefits**: No installation required, can run from USB drive, minimal system impact

### 2. Installer Distribution
- **File**: `PsychologicalRecords-v1.0.0-Installer.zip` (64.6 MB)
- **Built with**: cx_Freeze
- **Description**: Traditional Windows application distribution
- **Installation**: Extract and run `PsychologicalRecords.exe`
- **Benefits**: More comprehensive library inclusion, better for corporate environments

## System Requirements

- **Operating System**: Windows 10/11 (64-bit)
- **Memory**: 4 GB RAM minimum, 8 GB recommended
- **Storage**: 500 MB free space for installation and data
- **Display**: 1024x768 minimum resolution, 1920x1080 recommended

## Quick Start

1. Download your preferred distribution package
2. Verify integrity using the SHA256 checksums in `SHA256SUMS.txt`
3. Extract the ZIP file to your desired location
4. Run `PsychologicalRecords.exe`
5. Use default credentials: admin / admin123 (change immediately)

## Security Notes

- The application uses AES-256 encryption for data storage
- Patient data is stored securely in encrypted SQLite database
- Change default credentials immediately upon first login
- Regular backups are recommended
